# Карта мест (POI) — вариант 8

Лабораторные работы по Java. Все лабораторные — один проект, каждая следующая добавляется поверх предыдущей.

## Как запустить

Нужна Java 21 или новее.

```
./gradlew run          # Linux / macOS
gradlew.bat run        # Windows
```

## ЛР 1. Модель данных

| Файл | Что в нём |
| --- | --- |
| `Category.java` | перечисление категорий мест |
| `Place.java` | базовое место: id, название, категория, широта, долгота |
| `ModeratedPlace.java` | место «на модерации», только чтение |
| `Editable.java` | маркерный интерфейс «можно изменять» |
| `NetworkPlace.java` | сетевое место: можно изменять, есть сайт и телефон |
| `ErrorCode.java`, `CsvException.java` | своё исключение с кодом ошибки |
| `CsvFile.java` | чтение и запись CSV, битые строки пропускаются |
| `MainFrame.java` | окно: таблица, кнопки, диалоги |
| `Main.java` | точка входа |

Формат CSV: `type;id;name;category;latitude;longitude;website;phone`.
Файл `data/places.csv` специально содержит 5 битых строк, по одной на каждый код ошибки.

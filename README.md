# Карта мест (POI) — ЛР №1 «Модель данных»

Запуск: открыть папку в IntelliJ IDEA как Gradle-проект (JDK 21), запустить `ru.nstu.poi.Main`
или `gradlew run`. Тесты: `gradlew test`. Пример данных с битыми строками: `data/places.csv`.

## Пакеты
- `model` — Place (базовый), ModeratedPlace (read-only), NetworkPlace (редактируемый, сайт + телефон), Editable, enum Category/PlaceType, GeoLimits.
- `io` — формат CSV, парсер строки, загрузчик/запись, исключения с кодами CsvErrorCode.
- `service` — PlaceService: хранение и операции (добавить, изменить, загрузить, сохранить).
- `ui` — Swing: главное окно, модель таблицы, диалог добавления/редактирования.

## Формат CSV
`type;id;name;category;latitude;longitude;website;phone`, кодировка UTF-8, дробная часть через точку.

## Почему Editable с методом, а не маркер
Интерфейс содержит `validate()`, потому что правила корректности зависят от типа (у сетевого места
обязателен сайт и проверяется телефон). Метод держит правила рядом с данными, и их одинаково вызывают
диалог GUI, сервис и загрузчик CSV — проверка не дублируется. Маркер только сообщил бы «можно менять»,
а проверку пришлось бы писать отдельно в GUI (признак «god object»).
